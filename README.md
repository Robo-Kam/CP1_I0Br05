# CP1_I0Br05
CU Boulder ROBO5000 Challenge Problem 1 Project
Designed by Kam Kelly and Noel Craig

# Instructions
1. Download the main branch
2. Run Grid.py from the CP-1 directory
3. There is a prompt in the terminal that will ask for the grid size
4. Input a number into the terminal between 3 and 10 (inclusive)

Two separate plots will open:
The main plot shows all of the robots in the 'warehouse' grid space as well as a dashed line to their respective goals.
    Use the right arrow key to move forward in timesteps of the robot warehouse to see the visual representation of the robot movements to their goals.
The other plot shows the optimal path for each robot.  The left and right arrow keys can be used to cycle through each robots respective path.

Close both of the plots to end the program.
